# Project Features

## SCRUM-188 - Build Quick Resume Maker with Experience Input and PDF CV Export

### Feature Summary
A Quick Resume Maker application allowing users to manage experience records and download formatted PDF resumes.

### Key Features
- Dynamic experience, education, skills, and contact detail input forms with validation
- Live frontend preview of resume layout
- Backend PDF generation engine converting resume data into clean PDF documents
- Direct downloadable PDF export via REST API
