# Project Features

## SCRUM-63 — Water Tanker Booking & Fleet Management Platform

### Feature Summary
Unified Water Tanker Booking application allowing customers to order water, operators to dispatch tankers, drivers to track status in real-time, and admins to monitor demand analytics.

### Key Features
- Customer Self-Service Delivery Requests with delivery location, capacity requirements, and date/time scheduling.
- Operator Dispatch Dashboard for reviewing pending requests, checking tanker availability, and assigning drivers/tankers.
- Driver Mobile/Web Portal for viewing assigned tasks, updating delivery lifecycle states, and capturing delivery confirmations.
- Admin Monitoring & Demand Analytics Dashboard for tracking fleet utilization, demand spikes, and fulfillment metrics.
- Role-Based Access Control (RBAC) and Real-Time WebSocket updates for instantaneous delivery status synchronization.
