# Project Features

## SCRUM-185 - Local Weather Dashboard: Weather Forecasts & Temperature Trends

### Feature Summary
A web application dashboard that enables users to view current local weather conditions, multi-day forecasts, and interactive temperature trend charts for any searched city with temperature unit conversion.

### Key Features
- Location-Based Weather Forecast Display (current conditions, 7-day forecast)
- Interactive Temperature Trend Visual Charts (24-hour and 7-day trend analysis)
- Location Search & Temperature Unit Toggle (°F / °C)
