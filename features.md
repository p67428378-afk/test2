# Project Features

## SCRUM-232 - Expense Tracker System - Core Expense Management & Reporting

### Feature Summary
An expense tracker web application that allows users to manage income/expense records, view real-time balance and category analytics, configure category budgets with threshold alerts, and export data in CSV/PDF formats.

### Key Features
- Expense Entry & Categorization
- Transaction Management & Filtering
- Expense Dashboard & Summary Analytics
- Category & Budget Management
- Data Export & Reporting
