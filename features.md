# Project Features

## SCRUM-147 - Parking Fine Management System - Fine Lookup, Payment Status, and Admin Management

### Feature Summary
A Parking Fine Management System allowing vehicle owners to search fines and verify payment status, while enabling administrators to issue, update, void, and manage fine records securely.

### Key Features
- User Fine Viewing & Search by license plate or ticket reference
- Real-time Payment Status Verification
- Admin Fine Creation (CRUD - Create)
- Admin Fine Updating & Management (CRUD - Read, Update, Delete)
- Full-Stack Role-Based Access Control (RBAC) & Security
