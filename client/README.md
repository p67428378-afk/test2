# Tip Calculator Frontend

Interactive React application for calculating tips, custom percentages, and bill splitting across multiple people.

## Features

- Positive bill amount input with instant calculation
- Quick preset tip buttons (10%, 15%, 18%, 20%)
- Custom tip percentage input (0% to 100%)
- Equal bill splitting with per-person breakdown
- Responsive layout adhering to Figma specifications

## Local Setup & Development

1. Install dependencies:

   ```bash
   npm install
   ```

2. Configure environment:
   Ensure `VITE_API_BASE_URL` is configured in `.env` (defaults to `http://localhost:8000`).

3. Start dev server:

   ```bash
   npm run dev
   ```

4. Run unit tests:

   ```bash
   npm test
   ```

5. Build for production:
   ```bash
   npm run build
   ```
