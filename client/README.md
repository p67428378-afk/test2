# DG Cluster Assortment Advisor

This is the frontend client for the Dollar General Cluster Assortment Advisor.

## Client Setup

To run the client locally:

1. Navigate to the `client/` directory:

   ```bash
   cd client
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Run tests:
   ```bash
   npm run test
   ```

## Environment Variables

- `VITE_API_BASE_URL`: The base URL of the backend API (defaults to `http://localhost:8000`).
