# Project Features

## SCRUM-102 - WiFi Maintenance Tracker - Record Events & Track Costs

### Feature Summary
A web application that allows network administrators and property managers to record WiFi maintenance events, filter logs, and track maintenance costs using visual analytics.

### Key Features
- Record WiFi maintenance events (event date, hardware/location, maintenance type, vendor/technician, cost, description)
- Interactive cost tracking dashboard with total spend metrics and expense breakdown by category/location
- Filterable and searchable maintenance event history log
- Export maintenance logs and expense summaries to CSV/PDF reports
