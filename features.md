# Project Features

## SCRUM-234 - Hotel Management System — Core Booking, Guest, & Room Management

### Feature Summary
As a Hotel Operations Staff member (Desk Clerk / Manager), I want to manage room inventory, process guest reservations, execute check-in/check-out workflows, and view billing details, so that hotel operations run efficiently, room utilization is maximized, and guest satisfaction is maintained with seamless billing.

### Key Features
- Room Inventory & Availability Management
- Guest Reservation Processing & Management
- Check-In & Check-Out Workflows
- Billing & Invoice Calculation
