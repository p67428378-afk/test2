# Project Features

## SCRUM-120 - Interactive Alphabet & Numbers Learning Website for Kids (Ages 2-5)

### Feature Summary
An interactive, colorful, and easy-to-navigate website where toddlers aged 2 to 5 can learn alphabets and numbers through engaging, self-directed play.

### Key Features
- Interactive Alphabet Screen (A-Z) with animated cards and audio feedback.
- Interactive Numbers Screen (1-10) with counting animations and audio feedback.
- Kid-Friendly Navigation with large, colorful buttons and minimal text.
- Parent Dashboard to view child's progress (letters and numbers explored).
- RESTful API backend to persist progress and serve learning content.
