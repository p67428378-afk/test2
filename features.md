# Project Features

## SCRUM-224 - Character Name Generator - Genre-Based Unique Name Generation

### Feature Summary
Allows writers, gamers, and roleplayers to select character genres (Fantasy, Sci-Fi, Cyberpunk, Mystery, Historical) and instantly generate unique names.

### Key Features
- Genre selection dropdown / selector UI
- Unique name generation based on selected genre pool
- Custom quantity selection (1 to 10 names at once)
- One-click copy to clipboard with toast notification
- Input validation and RESTful error handling
