# Project Features

## SCRUM-79 ΓÇö User Story: Food Donation Management System — End-to-End Surplus Food Rescuing, NGO Claiming, Volunteer Delivery, and Freshness Monitoring

### Feature Summary
A full-stack Food Donation Management System that connects restaurant donors, NGOs, and delivery volunteers while monitoring food freshness and managing audit trails.

### Key Features
- Role-Based Access Control and Multi-Portal Authentication (Donor, NGO, Volunteer, Admin)
- Surplus Food Posting & Real-Time Freshness Monitoring (Fresh, Warning, Expired)
- NGO Claim Allocation and Request Handling (Full or partial claims)
- Volunteer Dispatch, Delivery Routing, and Digital Proof of Delivery
- Admin Oversight, Waste Analytics, and Audit Logs
