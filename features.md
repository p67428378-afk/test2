# Project Features

## SCRUM-236 - Digital Evidence Management System (DEMS) - Upload, Chain-of-Custody, Case Assignment, RBAC, & Audit Logging

### Feature Summary
Provides a secure, end-to-end platform for investigative teams to upload digital evidence files up to 5GB, calculate cryptographic SHA-256 hashes, maintain tamper-evident chain-of-custody ledgers, assign evidence to cases, enforce role-based permissions, and generate audit logs for every system interaction.

### Key Features
- Evidence Upload & Cryptographic SHA-256 Integrity Verification
- Immutable Chronological Chain-of-Custody Ledger
- Case Assignment & Metadata Categorization Dashboard
- Granular Role-Based Access Control (RBAC)
- Comprehensive Tamper-Evident Audit Logging
