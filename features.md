# Project Features

## SCRUM-156 - Watchlist App — Film Search and Ratings

### Feature Summary
A web application that allows movie enthusiasts to search for films, add them to a personal watchlist, and rate movies they have watched on a 1-5 star scale.

### Key Features
- Film Search by title with details (year, genre, poster)
- Add/remove films to/from a personal watchlist
- Rate watched movies on a 1-5 star scale
- Watchlist and Ratings dashboard with separate tabs
