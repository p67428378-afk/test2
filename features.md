# Project Features

## SCRUM-119 - Skill Exchange Platform: Skill Profiles, Match Finding & Exchange Requests

### Feature Summary
A skill exchange platform allowing users to profile skills to teach and learn, discover reciprocal exchange partners through automated matching, and manage skill exchange requests through a dedicated workflow dashboard.

### Key Features
- User Skill Profile Management (Teach & Learn lists with proficiency levels)
- Skill Match Discovery & Search Filtering (Intersections between skills to learn and teach)
- Exchange Request Workflow (Send, Accept, Reject, Cancel with status transitions)
- Exchange Request Management Dashboard (Incoming/Outgoing request inbox with status filters)
