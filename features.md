# Project Features

## SCRUM-115 - Create a ChatGPT-like Chat Application with Real-Time Streaming and Conversation History

### Feature Summary
A responsive, full-stack chat application that allows users to have real-time streaming conversations with an AI assistant, manage multiple chat sessions, and persist their conversation history.

### Key Features
- Responsive Chat Interface & User Interaction with collapsible sidebar and multi-line input
- Real-Time Streaming Responses using Server-Sent Events (SSE) with a Stop Generating button
- Conversation History Management persisted in PostgreSQL with UUIDs and UTC timestamps
- Sidebar Navigation & Session Management for creating, renaming, and deleting chat sessions
