# Aura Studio — Frontend Client

Photography Studio Management System React Application built with Vite and Tailwind CSS.

## Getting Started

### Installation

```bash
npm install
```

### Local Development

```bash
npm run dev
```

The dev server starts at `http://localhost:5173`.

### Environment Variables

- `VITE_API_BASE_URL`: Base URL for the FastAPI backend (default: `http://localhost:8000`)

### Running Tests

```bash
npm test
```
