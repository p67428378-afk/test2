# Project Features

## SCRUM-229 - Expense Tracker Application with Dashboard

### Feature Summary
An application enabling users to add, view, edit, and delete expenses with amount, category, date, and description fields, and view dashboard analytics for overall and category-wise spending.

### Key Features
- Expense CRUD operations (Create, Read, Update, Delete) with fields: amount, category, date, and description.
- Dashboard displaying aggregate metrics including total overall expenses and breakdown of expenses by category.
- Form validations and error handling for expense inputs.
