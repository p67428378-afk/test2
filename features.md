# Project Features

## SCRUM-210 - Build Shared Bill Splitter: Group Expense Entry & Individual Share Calculation

### Feature Summary
Allows users to create group expenses, split costs equally or customly, track net balances owed between members, and record settlement payments.

### Key Features
- Group expense entry with total amount, payer, date, description, category, and participating members
- Flexible share calculation (equal split, custom exact amounts, percentage split) with net balance tracking
- Settlement recording and itemized expense/settlement history overview
