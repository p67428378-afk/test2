# Project Features

## SCRUM-172 - Donation Management Portal - View Campaigns, Contribute, and Admin Campaign/Donation Management

### Feature Summary
Allows users to search, view, and donate to donation campaigns, while giving admins tools to manage campaigns and audit donation records.

### Key Features
- Campaign Catalog & Details: Browse active, upcoming, and completed donation campaigns with real-time progress indicators.
- Donation Processing: Contribute to campaigns securely with configurable payment methods and instant confirmation receipts.
- Admin Dashboard: Create, edit, pause, and close campaigns, as well as view and export donation audit records.
