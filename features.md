# Project Features

## SCRUM-222 - Build Board Game Scorer: Add Players and Tally Final Points

### Feature Summary
Allows users to add players, record game scores, automatically tally totals, and view a ranked leaderboard highlighting the winner.

### Key Features
- Player Management: Add multiple players by name
- Score Entry & Tallying: Input points per player and auto-calculate totals
- Leaderboard & Winner Declaration: Rank players highest to lowest and highlight the winner
