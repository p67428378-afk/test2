# Project Features

## SCRUM-106 - Interactive Healthy Habits Tracker for Kindergarten Kids

### Feature Summary
An interactive, gamified website where kindergarten children can track daily healthy habits (such as brushing teeth, washing hands, eating vegetables, and sleeping on time) to earn stars and streaks, while parents/teachers can manage active habits and monitor progress.

### Key Features
- Kid-Friendly Interactive Dashboard with animated habit cards.
- Gamified Reward System (Stars and Streaks) with visual feedback.
- Parent/Teacher Configuration Portal to manage active habits and view progress.
- RESTful API backend for progress tracking and habit management.
