# Project Features

## SCRUM-98 - EB Maintenance Tracker - Task Recording, Assignment, Cost Tracking, Deadlines & Completion

### Feature Summary
An Electricity Board Maintenance Tracker allowing users to create maintenance tasks, assign technicians, track estimated and actual costs, manage deadlines, and update task statuses to completion.

### Key Features
- Record Maintenance Tasks with title, description, location/equipment, priority, and status
- Task Assignment to designated technicians/staff
- Cost Tracking for estimated vs actual maintenance expenses
- Deadline Management with alerts for upcoming and overdue tasks
- Task Completion workflow with resolution logs and status transitions
