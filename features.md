# Project Features

## SCRUM-103 - Digital Queue System - Queue Joining, Number Generation, Position Checking, and Status Tracking

### Feature Summary
A web-based digital queue application allowing customers to virtually join a service queue, receive a unique queue ticket, track their line position in real-time, and view their service status.

### Key Features
- Queue joining and unique ticket number generation
- Real-time position checking and wait time estimation
- Service status tracking (Waiting, In Progress, Completed, Cancelled)
- Full-stack web application with React UI and FastAPI REST backend
