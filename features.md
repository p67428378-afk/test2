# Project Features

## SCRUM-190 - Bill Splitter - Enter Group Expenses and Calculate Individual Shares

### Feature Summary
This feature allows users to form groups, enter shared expenses with custom or equal split options, and automatically view calculated individual shares and debt settlement summaries.

### Key Features
- Group expense entry with title, amount, payer, date, category, and participants
- Flexible split rules (equal, custom percentages, fixed amounts)
- Automatic calculation of individual balances and simplified settlement plans
- Input validation for negative amounts and improper split percentages
