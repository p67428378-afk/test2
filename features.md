# Project Features

## SCRUM-205 - Customizable Password & Secure Key Generator with One-Click Copy

### Feature Summary
Allows end users to generate customizable, cryptographically secure passwords and copy them with one click.

### Key Features
- Password Length Customization (8 to 128 characters, default 16)
- Character Set Selection & Complexity Controls (Uppercase, Lowercase, Digits, Symbols)
- Cryptographically Secure Password Generation via Python secrets module
- One-Click Secure Clipboard Copying with visual feedback
- Real-time Password Strength Meter
