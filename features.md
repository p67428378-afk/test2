# Project Features

## SCRUM-57 — Equipment Rental Management System

### Feature Summary
An equipment rental platform where users can browse, reserve, and rent cameras, drones, or construction tools, manage security deposits, track rental periods, and calculate late fees upon return.

### Key Features
- Equipment Catalog & Availability Search: Browse cameras, drones, and tools with real-time stock and daily rate tracking.
- Rental Reservation & Deposit Handling: Reserve equipment for specified dates with deposit calculation and pre-authorization.
- Rental Period & Lifecycle Tracking: Track active rentals, status transitions (RESERVED, CHECKED_OUT, ACTIVE, OVERDUE), and automated reminders.
- Return Check-In & Late Fee Calculation: Process equipment returns, assess condition, and calculate daily late fee penalties against deposits.
