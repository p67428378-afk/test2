# Project Features

## SCRUM-121 - Build Study Flashcard App

### Feature Summary
This feature allows users to create and organize flashcard decks, add cards with questions and answers, and take interactive quizzes to test their knowledge with score tracking.

### Key Features
- Deck creation, viewing, updating, and deletion
- Flashcard management (front and back content) within decks
- Interactive quiz mode with card flipping and correct/incorrect marking
- Quiz results summary with score percentage and time tracking
