# Project Features

## SCRUM-219 - Customer Feedback Analyzer - Ingestion, AI Sentiment & Admin Insights Dashboard

### Feature Summary
Allows end users to submit text feedback and ratings while providing administrators with an AI-powered dashboard that aggregates sentiment metrics and highlights recurring issues.

### Key Features
- Feedback submission interface for end users
- AI sentiment analysis and common issue categorization
- Admin insights dashboard for aggregated feedback trends and metrics
- Role-based access control securing admin insights
