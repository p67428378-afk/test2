### Feature Summary
Users can report lost or found items, view AI-generated match recommendations, submit ownership claims, and track claim histories. Admins can verify proof of ownership, manage claims, and maintain an immutable audit trail.

### Key Features
- Item Reporting (Lost and Found) with detailed metadata and image uploads
- AI-Powered Match Suggestions based on attribute vector similarity scoring (0-100%)
- Admin Ownership Verification Workflow for approving or rejecting claims
- Claim History and Audit Trail tracking item status transitions and admin decisions
