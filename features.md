# Project Features

## SCRUM-219 - Customer Feedback Analyzer - Ingestion, AI Sentiment, Admin Insights Dashboard, Real-Time Alerts & Export

### Feature Summary
Allows end users to submit rated feedback and administrators to view AI sentiment trends, receive alerts on critical negative feedback, and export feedback reports.

### Key Features
- Feedback Ingestion & Submission
- AI Sentiment Analysis & Common Issue Categorization
- Admin Insights Dashboard & Historical Sentiment Trends
- Real-Time Automated Alerting for Critical Negative Feedback
- Feedback Insights Export (CSV / Data Download)
- Security & Role-Based Access Control (RBAC)
