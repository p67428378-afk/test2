# Project Features

## SCRUM-230 - Simple Calculator Web Application

### Feature Summary
Perform basic calculations (add, subtract, multiply, divide) via an interactive web interface with instantaneous error handling and responsive layout.

### Key Features
- Basic Mathematical Operations (addition, subtraction, multiplication, division)
- Input Validation & Error Handling (handling division by zero)
- User Interface Responsiveness (keypad and visual display for desktop and mobile)
