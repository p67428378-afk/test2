# Visitor Management System for Residential Communities

## Overview
A comprehensive Visitor Management System built with FastAPI (Python 3.11) and React (Vite + Tailwind CSS). Provides visitor pre-approvals with cryptographically signed, time-bound QR tokens, gate QR validation, delivery package tracking with overdue reminders, and security alert broadcasting with a 60-second false-alarm supervisor cancellation window.

## Features
- **Visitor Pre-approval & Time-bound QR Generation**: Pre-approve visitors for a specified time window with signed HMAC/JWT QR code tokens.
- **QR Entry Validation**: Gate guard terminal endpoint to validate QR tokens, detect reuse/expiration, and log gate entries.
- **Delivery Package Tracking**: Guard logging for incoming packages per unit number, package state transitions, and 48-hour overdue reminders.
- **Security Alerts & Emergency Broadcasting**: Broadcast real-time emergency alerts with location tags and 60-second supervisor cancellation window.

## Backend Setup & Local Execution

### Prerequisites
- Python 3.11+
- Virtual environment (`venv` or `uv`)

### Environment Variables
Copy `.env.example` to `.env`:
```bash
cp server/.env.example .env
```

Key environment variables:
- `DATABASE_URL`: Database connection string (default: `sqlite:////tmp/app.db`)
- `JWT_SECRET_KEY`: Secret key for JWT tokens
- `QR_SECRET_KEY`: Secret key for signing QR tokens
- `ALLOWED_ORIGINS`: Comma-separated CORS origins (default: `http://localhost:5173,http://localhost:3000`)

### Installation & Server Start
```bash
# Navigate to server directory
cd server

# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Start FastAPI development server
uvicorn server.main:app --host 0.0.0.0 --port 8000 --reload
```
API Documentation will be available at `http://localhost:8000/docs`.

### Running Tests
```bash
pytest server/tests/
```

## Full-Stack Local Development

2. **Frontend**:

## Full-Stack Local Development

To run both backend and frontend together locally:

### 1. Environment Setup
```bash
# Copy the example environment file
cp .env.example .env
```

### 2. Start the Backend (Terminal 1)
```bash
python -m venv server/.venv
source server/.venv/bin/activate  # On Windows: server\.venv\Scripts\activate
pip install -r server/requirements.txt
python -m uvicorn server.main:app --reload --host 0.0.0.0 --port 8000
```
Backend API: `http://localhost:8000` | API Docs: `http://localhost:8000/docs`

### 3. Start the Frontend (Terminal 2)
```bash
cd client
npm install
npm run dev
```
Frontend: `http://localhost:5173`

The frontend connects to the backend API at `http://localhost:8000` by default via the `VITE_API_BASE_URL` environment variable.

### 4. Test Credentials
If the app has authentication, the backend seeds ready-to-use accounts on startup
(idempotent). These are guaranteed logged-in-able — every activation/verification
gate (`is_active`, `is_verified`, `email_verified`, `disabled`) is set to the
permissive value, so no manual DB step is needed:
- **Regular user** — Email: `test@example.com`, Password: `testpassword`
- **Admin user** (only when the app has roles/RBAC) — Email: `admin@example.com`, Password: `adminpassword`, role: `admin`

Passwords are stored hashed with the app's own hashing utility (never in plaintext).
