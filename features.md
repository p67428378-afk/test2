# Project Features

## SCRUM-148 - Weather Dashboard: View Forecasts and Temperature Trends

### Feature Summary
A responsive web application that allows users to search for cities, view current weather conditions, see a 5-day forecast, and visualize temperature trends on an interactive chart.

### Key Features
- City search and selection
- Current weather and 5-day forecast display
- Interactive temperature trend chart
- Fahrenheit / Celsius unit toggle
