# Project Features

## SCRUM-173 - Browser Markdown Editor with Formatting Toolbar and Live HTML Preview

### Feature Summary
A web-based Markdown Editor with formatting toolbar, live HTML preview, and document auto-saving and loading features.

### Key Features
- Markdown Input Area with syntax highlighting
- Formatting Toolbar (Bold, Italic, Headings, Lists, Links, Code Blocks)
- Live HTML Preview pane with sub-100ms latency
- Full-Stack Integration with REST API for document save/load
