# DG Cluster Assortment Advisor Dashboard

This is the frontend client for the DG Cluster Assortment Advisor Dashboard.

## Setup and Installation

1. Navigate to the `client` directory:

   ```bash
   cd client
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file (or copy from `.env.example`):

   ```bash
   cp .env.example .env
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## Available Commands

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Builds the production-ready assets.
- `npm run test`: Runs unit tests using Vitest.
- `npm run lint`: Lints the codebase.
