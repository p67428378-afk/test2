# Project Features

## SCRUM-255 - Web Application to View Tourist Places in and Around Kerala

### Feature Summary
A web application enabling users to explore tourist places in and around Kerala by category, district, search terms, and filters, viewing rich detail pages with map directions, ratings, and reviews.

### Key Features
- Destination Catalog & Categorization (Hill Stations, Backwaters, Beaches, Wildlife, Heritage)
- Search & Filter System (by keyword, district, category, visit window, fee range)
- Detailed Spot View & Interactive Media (gallery, best time, fees, map embed, nearby spots)
- User Reviews & Ratings (1-5 star ratings, text reviews, user feedback)
- Responsive Web Design & Offline Caching (fast load times, mobile friendly)
