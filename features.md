# Project Features

## SCRUM-181 - Browser Markdown Editor with Text Formatting and Live HTML Preview

### Feature Summary
Allows users to write and edit Markdown formatted text in the browser with live, real-time HTML preview rendering, formatting toolbar controls, and document export/copy features.

### Key Features
- Markdown Text Editing & Formatting Toolbar
- Live Side-by-Side Real-Time HTML Preview
- Export to Markdown (.md) and Copy HTML/Markdown to Clipboard
- XSS Sanitization and Error Handling
