# Project Features

## SCRUM-191 - Interactive Digital Learning Platform with Animations for 1st Year MBBS Students

### Feature Summary
An interactive digital learning platform for 1st-year MBBS students to study medical subjects using interactive image viewers with hotspot annotations and layer toggling, alongside digital animations with embedded quiz checkpoints.

### Key Features
- High-Resolution Interactive Image Viewer with zoom, pan, hotspot annotations, and layer toggling
- Digital Learning Animation Player with play/pause, speed controls, step-by-step frame scrubbing, and interactive quiz overlays
- Interactive Self-Assessment & Quizzes linked to specific images and animation modules
- Student Learning Dashboard for tracking module completion, quiz scores, and study progress
