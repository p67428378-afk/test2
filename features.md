# Project Features

## SCRUM-213 - Build Photography Studio Management System

### Feature Summary
As a photography studio admin, photographer, or customer, I can manage studio bookings, schedule photographer availability, customize photo packages, track deposit and balance payments, and access interactive control dashboards and RESTful API endpoints for expanded feature workflows.

### Key Features
- Customer Session Booking with slot hold & conflict prevention
- Photographer Availability Management with working hours and date blocks
- Package Selection & Dynamic Add-on Customization
- Payment Tracking & Balance Settlement Ledger
- Photoshoot Recording & Proof Gallery Links
- Interactive Control Dashboard & Real-Time Status Widgets
- RESTful Feature Endpoints (/api/v1/features) with Pydantic validation
- SQLAlchemy 2.x Extended Data Models with UTC timestamp tracking
- CORS Middleware and environment-configurable API Base URL
