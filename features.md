# Project Features

## SCRUM-276 - Vendor Contract Management Portal

### Feature Summary
A web portal enabling procurement teams and external vendors to draft, version, negotiate, approve, track expiry, and send renewal reminders for vendor contracts.

### Key Features
- Contract Drafting and Creation
- Contract Versioning and Change Tracking
- Negotiation Comments and Collaboration
- Multi-Stage Approval Workflows
- Expiry Tracking and Automated Renewal Reminders
