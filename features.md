# Project Features

## SCRUM-187 - Employee Leave Management System

### Feature Summary
An Employee Leave Management System where employees can apply for leave, view their leave balance and request history, and managers can review, approve, or reject leave applications.

### Key Features
- Employee Leave Application: Form to select leave type, date range, and reason with automatic day calculation.
- Manager Approval Dashboard: Interface for managers to view pending requests and approve/reject with feedback.
- User Leave History & Balance: History view of past requests with remaining balance tracking.
- RESTful API & Security: Built with FastAPI backend and React frontend adhering to Constitution standards.
