# Project Features

## SCRUM-215 - LMS Portal for College Students - Course Management, Assignments, and Student Dashboard

### Feature Summary
An LMS portal allowing college students to log in, view enrolled courses, access lecture materials, submit assignments online, and track grades.

### Key Features
- Student and Faculty Authentication & RBAC Dashboard
- Course Catalog Browsing & Module Material Viewer
- Assignment Upload, Timestamp Tracking & Grade Reporting
